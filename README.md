# Homebrew Tap

This tap provides Freeshots for macOS.

After the first tagged Freeshots release, install it with:

```sh
brew install --cask l2fprod/tap/freeshots
```

The Freeshots GitHub Actions release workflow publishes `Casks/freeshots.rb` when a `vMAJOR.MINOR.PATCH` tag is pushed. Builds from `main` are available as Actions artifacts and do not update this tap.
